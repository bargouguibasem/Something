# BARGOUGUI test 3D files

Mannequins built from the CC0 MakeHuman base mesh; garments draped with Blender cloth simulation.
Draco-compressed glTF, metres, Y up, feet at y=0, facing +Z. Neutral (no materials): the BARGOUGUI site tints them.

- `<female|male>_body.glb` - faceless shop-window mannequin (female 1.70 m, male 1.80 m)
- `_tee` boxy drop-shoulder tee, `_longsleeve` shirt / pajama top, `_hoodie`, `_jacket` cropped boxy jacket with funnel collar, `_trousers`
